# Gestión Online VUT Galicia

Web estática profesional para presentar servicios de alta VUT, gestión administrativa online, gestión comercial y comunicación previa para viviendas turísticas en Galicia.

## Archivos principales

- `index.html`
- `styles.css`
- `script.js`
- `assets/`

## Publicación

Proyecto preparado para GitHub Pages, Cloudflare Pages, Netlify o cualquier hosting estático.
